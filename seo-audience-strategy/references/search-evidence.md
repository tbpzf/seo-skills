# Search evidence for a reader brief

Use this branch when queries have competing meanings or the expected answer,
format, or angle needs evidence. Apply the
[helpful-content standard](../../distinctive-content/references/helpful-content.md).

1. Start with supplied reader/query data and inspect relevant supplied URLs,
   artifacts, and SERP notes when accessible. Distinguish customer observations,
   query wording, published content, and measured search behavior; each supports
   a different inference.
2. If a material ambiguity remains and live search is available, inspect targeted
   results for the relevant query and market. Note the result types, format,
   angles, and reader questions. Open relevant pages when assessing their actual
   answer or a proposed gap; a search snippet alone cannot establish coverage.
3. Record the actual references, query and context, date/market when relevant,
   observations, and competing interpretations. Explain why the selected
   interpretation fits this reader. A mixed SERP may support several intents;
   identify the coherent one the page will serve and what belongs elsewhere.
4. Reconcile search expectations with direct audience evidence, available
   expertise, and product truth. State which disagreement remains unresolved;
   neither popularity nor a format shared by top results proves usefulness.
5. If inspection is unavailable or inconclusive, record the sources checked and
   the specific uncertainty. Use an explicitly provisional interpretation when
   it can support a safe brief. Ask for missing context only when the ambiguity
   prevents choosing a responsible promise, or recommend deferring that choice.

The output is an intent interpretation, expected answer/artifact, content
type/format, supporting observations and references, competing interpretations,
and uncertainty. Keep coverage and novelty claims limited to the comparison
actually inspected; explain useful added value without claiming an unobserved
gap. Search Console impressions and clicks reveal how a page is found, not by
themselves whether it fulfills the task or should become a new page.
