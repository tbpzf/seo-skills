# Supplied keywords in guest posts

Apply this reference when the user provides a primary keyword or long-tail
phrases. The host publication's readers, contributor guidelines, and editorial
angle determine which phrases belong in the article.

## Plan each phrase

Keep the supplied inventory verbatim and mark the primary term. Record any
user-prohibited phrase even when it is outside the positive keyword list. For each term,
record the reader question or task it expresses, whether it fits the article's
thesis and host rules, any user prohibition, and one of these decisions:

- **Use:** Name the section or point where the wording helps the reader.
- **Use a natural variant:** Name the wording and section when an exact phrase
  would interrupt the article or conflict with the host's style.
- **Omit:** State why, such as a different search intent, weak editorial fit,
  unsupported product implication, a user prohibition, or a host restriction.

The primary keyword is an input to the angle, not a mandatory headline or H1.
When it does not fit the host's readers, propose a fitting angle and disclose
the mismatch. If the host, its reader evidence, or relevant rules cannot be
checked, mark affected keyword decisions provisional.
Do not expand the supplied list unless the user requests keyword research. Use
natural frequency; apply an explicit user-supplied placement or count request
only when it fits the host's rules and the prose, and flag a conflict instead
of forcing it.

## Check the draft

Compare every supplied term with the article body. In submission notes, record
the actual disposition of each phrase: exact wording and location, natural
variant and location, or omitted with a reason. Explain changes from the brief.
Check prohibited terms are absent. Check requested placements or counts only
when the user explicitly supplied them and the host permits them. Unless the
user or host specifies another scope, count article-body text and exclude the
title, byline, disclosure, and submission notes. Match case-insensitively; a
complete shorter phrase inside a longer exact phrase counts for both. For each
user-set target, report actual versus target, or `unverifiable` with the reason.
Mark a conflicting target unmet rather than changing accurate prose or host
style to hit a number. Do not create a product link or anchor-text placement
to satisfy a keyword request.
