## 星球正文

把 Claude Code / Codex 接进本星球,当成你自己的 SEO 知识库

星球里很多帖子只有一段摘要加一条原文链接,有的同学说看不懂,或者懒得一条条点开。现在有个更省事的办法:知识星球官方出了 AI 接入工具(zsxq-cli + 知识星球 Skill),装好以后,你在 Claude Code 或 Codex 里直接用中文提问,AI 会去星球里搜帖子,再帮你打开原文链接,用大白话讲给你听。

它用的是你自己的星球账号,只能看到你已经加入的星球,不会碰别的东西。

一、怎么装(5 分钟)
1. 电脑上先装好 Node.js 18 以上版本(终端输入 node -v 能看到版本号就行)。
2. 打开 Claude Code 或 Codex,把下面这句话原样发给它,它会自己装:
帮我安装知识星球 Skill:[https://garden.zsxq.com/skill/INSTALL.md](<https://garden.zsxq.com/skill/INSTALL.md>)
3. 装完 AI 会给你一个授权链接和验证码,用浏览器打开、确认授权,就装好了。

二、装好以后可以这么问(直接复制改关键词)
1. 在「SEO日报」星球里搜关于 AI Overviews 的帖子,列出标题和一句话总结。
2. 把这几条帖子里的原文链接打开,用大白话给我讲讲每篇讲了什么,我是 SEO 新手。
3. 星球最近一周发了哪些帖子?按 SEO / AI 搜索 / 工具 分类整理给我。
4. 我做外贸 B2B 独立站,星球里哪些帖子的方法我现在就能用上?给我列个清单。
5. 帮我看看星球里关于 GSC 的帖子,里面提到的数字和做法汇总成一张表。

三、想做成本地知识库(进阶,可选)
可以让 AI 把星球帖子一页页拉下来,每个帖子存成一个 Markdown 文件,顺便把原文链接里的文章也抓下来存好。之后你就在本地文件夹里提问,AI 回答会更快、更完整。直接跟 AI 说:"把 SEO日报 星球的帖子全部拉到本地,每篇存一个 md 文件,并抓取原文",它会一步步做。

四、几点注意
1. 有的网站挡爬虫或有付费墙,AI 打不开原文,这种只能看帖子里的摘要。
2. AI 可能会讲错,看到关键数字最好回原文核对一下。
3. 这个工具也能发帖、评论,但它每次写入前都会先问你,别让它乱发。
4. 拉到本地的内容仅供自己学习使用,请不要外传。

# 知识星球 Skill 安装指南

本文档供 AI Agent 阅读并执行，帮助用户完成知识星球 Skill 的安装与配置。

## 前置条件

- Node.js >= 18（执行 `node -v` 检查）

## 安装步骤

### 1. 安装 CLI 工具

```bash
npm install -g zsxq-cli
```

### 2. 安装 Skill

优先使用 GitHub（海外用户）：

```bash
npx skills add https://github.com/unnoo/zsxq-skill --yes --global
```

如果 GitHub 不可达，使用 Gitee 备用通道（国内用户）：

```bash
npx skills add https://gitee.com/unnoo/zsxq-skill --yes --global
```

**WorkBuddy 用户**：安装完成后，需要将已安装的 zsxq skill 文件同步到 WorkBuddy 本地技能目录 `~/.workbuddy/skills/` 下，确保 WorkBuddy 能够识别并加载这些技能。

### 3. 登录知识星球账号

```bash
zsxq-cli auth login
```

执行后终端会输出授权链接与设备验证码。将链接提供给用户，让用户在浏览器中打开并确认授权。等待用户确认后即可开始使用。

## 网络受限时的备选方案

如果上述地址均不可达，可从以下地址下载离线包手动安装：

```
https://garden.zsxq.com/skill/zsxq-skills.zip
```

下载解压后执行：

```bash
npx skills add ./zsxq-skill --yes
```

## 安装完成

安装并登录后，AI Agent 即可调用以下技能：

| 技能          | 用途                           |
| ------------- | ------------------------------ |
| `zsxq-group`  | 浏览星球、搜索成员             |
| `zsxq-topic`  | 搜索、发布、编辑主题，评论回答 |
| `zsxq-note`   | 创建、编辑、管理笔记           |
| `zsxq-user`   | 查看用户信息与足迹             |
| `zsxq-shared` | 认证授权、通用工具             |

## 从旧版升级

如果这台机器装过旧版的 5 个技能（`zsxq-shared`、`zsxq-group`、`zsxq-topic`、`zsxq-user`、`zsxq-note`），完成上述安装后对 AI 说：

> 检查并迁移旧版知识星球 skill

AI 会先扫描各安装位置并出具报告，经用户确认后才移动文件（先备份、可回滚）。仅检查不清理也可以，说「只检查旧版 zsxq skill」即可。
