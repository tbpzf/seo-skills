So this seems appropriate to talk about since I just gave a brightonSEO talk on our data study of 28K+ fan out queries from ChatGPT and Gemini. Over the past few months there have been quite a few good articles on extracting Search Console fan-out searches so I'm going to round up my favorite methods so far.

1. Filter For Queries With 10+ Words: This is a regex that I created on an article on the Nectiv site. It will automatically extract queries that are 10+ words in length which generally will give you conversational data: https://lnkd.in/eNNQAnTC

Query Filter: ^(?:\S+\s+){9,}\S+$

2. ChatGPT "Site:" Searches: In our data study, we found that ChatGPT performed "site:" searches in 65% of all of the fan-out queries. Lily Ray had the brilliant idea that these could be mined in Search Console: https://lnkd.in/eTTYup7Q

Query Filter: site:

3. Filter For Conversation User Prompt: Jean-Christophe Chouinard published an epic Regex that looks at conversational searches where users use phrases such as "Please", "Cancel", "Organize" etc. It's huge so I won't copy paste the whole thing here but you can find it on this post: https://lnkd.in/eJEWzxKx

4. AI Mode Query Classifier: Suganthan Mohanadasan actually created his own tool where you can import your entire Search Console data and it will use ML to actually find the queries that should be conversational prompts. You can find it here: https://lnkd.in/eQZN-4sG
