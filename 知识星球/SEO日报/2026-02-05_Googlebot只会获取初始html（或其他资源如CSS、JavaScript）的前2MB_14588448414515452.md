# Googlebot只会获取初始html（或其他资源如CSS、JavaScript）的前2MB

- 发布时间：2026-02-05T15:32:58.775+0800
- 作者：虾虾
- 星球原帖：[查看帖子](https://wx.zsxq.com/group/88882458825452/topic/14588448414515452)

## 星球正文

Googlebot只会获取初始html（或其他资源如CSS、JavaScript）的前2MB
你可以通过打开开发工具>网络面板，按文档筛选并硬重载页面来快速检查，关键是尺寸栏里的尺寸较大，也就是未压缩的大小。

注意，这是按资源计算的，所以你可以有一个1MB的HTML文档、一个1MB的CSS文件和1MB的JavaScript文件，这样也没问题 #工具#
