## 星球正文

Screaming Frog 的“JS Word Count %”功能可以显示页面内容中有多少依赖于 JS。这段文字可能在 Google 和 LLM 搜索引擎中存在索引问题： 

这是我在使用  Screaming Frog 时最喜欢生成的报告之一，尤其是在分析 Google 和 LLM 索引问题时。Screaming Frog 实际上有一个专门的“JavaScript”报告部分，可以提供关于 JS 在整个网站中如何使用的各种视图。 

在这份报告中，您可以清楚地看到单个 URL 的内容有多少是由 JavaScript 控制的。以下是查找该报告的方法： 

1. 打开尖叫蛙。 
2. 导航至“配置”>“蜘蛛”>“渲染”
3. 从渲染下拉菜单中选择“JavaScript”。
4. 转到配置 > 爬虫 > 渲染，确保“存储 HTML”和“存储渲染后的 HTML”已选中。 
5. 以蜘蛛模式开始爬行
6. 在右侧边栏中，导航至“JavaScript”>“包含 JavaScript 内容”。

在这里，您可以看到 Screaming Frog 抓取的所有 URL，以及“JavaScript 变化百分比”和“字数变化”。您可以大致了解有多少内容存在被 Google（风险较低）或 LLM（风险高得多）抓取的潜在问题。
