## 星球正文

专有数据 + 使用 CLAUDE 和 Perplexity 进行事实核查


人工智能首先生成一个草稿。然后，它不会检查你的整篇文章，而是将其拆解。它会将每个论点分解成一个个独立的事实。
例如：
“特斯拉 Model S 的续航里程为 600 公里，售价为 9 万欧元。”
人工智能分别检查了三个原子。
原子 A： 模型。 原子 B： 自主性。 原子 C： 价格。
如果你写 “特斯拉是一款价格昂贵但续航里程长的汽车”，你的话将不会被引用。
这是个好消息。这意味着，如果我明天创建一个和你一样的网站，主题也相同，但如果我没有相关的专业知识，那么我永远都会落后。


数据 = 更佳的背景信息
1. 内部数据 （您在 Claude 中的项目）：价格、设备、服务、到货流程、促销优惠。这些数据来自您，因此最容易被误解，因为如果我弄错了，就会直接在您的网站上做出虚假的商业承诺。现阶段请勿抓取网络数据。
2. 外部数据 （网络资源）：天气、本地活动、距离、旅游数据。这些数据我从第三方来源（例如 climate-data.org、.gov 等）获取，更容易获取和验证。现在许多 API 都支持收集可靠的数据。
然后，所有内容将存储在 NotebookLM 或 Claude 项目中。
在创建文章时可以重复使用这些数据，也可以向现有文章添加数据。
有两种处理方式：
1.添加上下文数据
2.撰写文章时添加数据

属于你的数据只能由你验证。而通过 LLM 抓取的数据，其所有权必须由第三方来源验证。切勿将两者混淆。


您的文章已准备就绪；请使用以下提示对文章进行事实核查（通过 Perplexity 运行）.

提示词 ：
您是一位资深的事实核查员，专门负责网络内容和搜索引擎优化。

你的任务：验证文本（文章、帖子、视频脚本、销售页面）的可靠性。

分析以下文本并：

提取所有可验证的事实主张（数字、日期、排名、研究引文、市场数据、法规、机构名称等）。

对于每条陈述，请注明： a) 原文引用（摘自文本） b) 您的判断：准确 / 近似（需改写） / 错误或无来源 c) 简要说明（1-3 句话） d) 如有必要，请提供更正/更可靠的版本 e) 一到两个可靠的外部来源（标题 + 域名，无需完整 URL）

重要的方法论限制：如果您没有 ≥ 80% 的把握，请将信息归类为“近似值/需要重新表述”或“无法验证”，并提供保守的版本。不要猜测精确数字：最好使用数量级（“大约”、“介于 X 和 Y 之间”、“数量级为”）。

预期输出格式（必填）：
第一部分 – 事实陈述列表 [原文引用] 结论：…… 理由：…… 建议的改写：…… 参考资料：……
第 2 部分——虚假信息的主要风险 列出了 3-5 个风险最大的方面（可疑的数字、滥用因果关系、未经证实的概括……）。
第 3 部分 – SEO 建议/可信度 如何重新措辞或引用来源以最大限度地提高 EEAT（准确性、主要来源、日期、统计数据的谨慎性）。
待核实文本： [在此处粘贴您的 SEO 文本以进行核实]

然后，根据所得结果进行调整。#写作#
