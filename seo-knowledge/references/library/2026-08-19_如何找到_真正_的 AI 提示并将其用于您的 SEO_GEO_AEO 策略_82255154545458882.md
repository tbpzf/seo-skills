How are your customers prompting AI platforms like ChatGPT, Gemini, Claude, or AI Mode?

This question has been one of the biggest ones in the SEO industry for a few years now, because we are taught to live in the “keyword-based” world.

The answer came from Google, albeit an unofficial one.

A few days ago, John Mueller [confirmed](https://www.reddit.com/r/AISearchAnalytics/comments/1vj03lc/ai_mode_prompts_are_recorded_in_search_console/) that Search Console recorded AI Mode prompts as queries.

So now we have an official confirmation that some of Search Console’s Performance section could give us a glimpse into real people’s prompting.

**>>>>> [Please join us to discuss this topic and bring your questions!](https://www.linkedin.com/events/7495240338371035136/)**

So let me share how to pull that prompt data from Google and how to use it (I’d welcome some more ideas here):

## How to find real prompts in Google’s Search ConsoleSVG Image

**1. Search Console query filters**

Prompts are likely to be longer, so you can easily find those by using a regex:
> ([^” “]*\s){10,}?

[SVG ImageSVG Image](https://substackcdn.com/image/fetch/$s_!zrtl!,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2F504c1698-1e1d-4ed4-8e24-fa3faf9bebab_1080x1090.png)

There’s another regex shared by Jean-Christophe Chouinard on [Linkedin](https://www.linkedin.com/posts/jeanchristophechouinard_every-since-barry-shared-that-ai-mode-query-share-7493679015984099328-olbi/) that filters likely “follow-up” queries, like “yes”, “please”, etc..

Note: For high-traffic properties, you will only be able to see queries that send at least some clicks. Since AI Mode might be sending none, you will miss those unless you access the SC data through the API.

Which brings us to a free API-based solution:

**2. A Google Spreadsheet extension**

I’ve been using this [Google Spreadsheet extension](https://workspace.google.com/marketplace/app/search_analytics_for_sheets/1035646374811) for many years, and it turns out to be useful for this task as well. All you need:

- Install and authenticate it

- Choose the website you want to run the report

- Group by query and use the regex above

From there, you can pull 25,000 queries that use the built-in Gemini capabilities to analyze and group the data:

[SVG ImageSVG Image](https://substackcdn.com/image/fetch/$s_!LLKJ!,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2F2ac90cb3-cad1-4ffb-a666-fadad35d52fd_1192x1440.png)

**3. A free tool**

[This may be a vibe-coded tool](https://www.reddit.com/r/SEO_for_AI/comments/1vr6yz0/a_free_tool_to_find_ai_mode_prompts_in_googles/), but it is a very useful one! It is free; it pulls data from your Search Console (so it does need access to your account), but it does some useful things:

- Pull likely queries that are AI Mode prompts

- It categorizes prompts by topics and intent

- It shows impressions for each prompt

- It blocks “likely bot” prompts

You can export everything into a spreadsheet for further analysis:

## Prompt impressions: How to find *real, human* promptsSVG Image

The major question I had: “Why do some of these prompts have such insane impression numbers? How many types can the same prompts be logically used by different people?”

Well, these are likely to be prompt tracking software running these prompts in the AI Mode. So these may not be actual human prompts. Instead, these are what marketers *think* the prompts may be. This is still a good insight into what your possible competitors are focusing on.

If you really want to know what people type as a prompt to an LLM, **keep an eye on 1- or 0-impression queries**.

## Bing’s AI query report vs Google’s query reportSVG Image

Another popular confusion: Bing AI section already reports on AI prompts.

No, it does not.

Bing Webmaster Tools gives you the grounding query report, i.e., what its LLM (Copilot) searches when a human being asks a question. There’s no report on what people are actually prompting.

While this is still quite a useful report, it gives no insight into real human interactions with an AI platform.

## What to do with the prompt dataSVG Image

The answer to this question is going to keep evolving because this is the new data we are dealing with.

From my personal perspective, so far:

- Use AI (ChatGPT, Gemini, Claude) to categorize and understand the prompt trends

- Better optimize the ranking URLs to address those questions

- Refine your prompt tracking strategy (chances are, you have some essential prompts missing), but don’t try to track each and every one of those prompts.
