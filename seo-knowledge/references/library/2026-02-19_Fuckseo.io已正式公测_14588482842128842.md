PRINCIPLES原则

## Three choices we made early. And kept making.三个一开始就定下、一直没变的选择。

GSC gives you data. Most tools give you charts. We wanted the part in between — the part that says “fix this page first”, and means it.GSC 给你数据，大多数工具给你图表。我们想要的是中间那一环——明确告诉你“先修这一页”，而且说到做到。

01

### Decay before the drop.在暴跌之前发现衰退。

Every page scored month-over-month across 12 months — so you fix dying pages before traffic falls off the cliff, not after.每个页面按月打分，覆盖 12 个月——在流量掉下悬崖之前修好正在衰退的页面，而不是事后补救。

02

### Live, not stored.实时读取，不存数据。

Every number comes straight from the Search Console API when you open it. No nightly sync, no database copy of your data — a same-day cache at most.每个数字都在你打开时直接从 Search Console API 读取。没有夜间同步，数据库里没有你的数据副本——最多只有当天的缓存。

03

### MCP-native, day one.从第一天起原生支持 MCP。

Claude Desktop, Claude Code and Codex talk to your GSC data over an OAuth-secured MCP endpoint. The agent reads, decides, ships.Claude Desktop、Claude Code 和 Codex 通过 OAuth 保护的 MCP 接口读取你的 GSC 数据。AI 读数据、做判断、直接动手。
