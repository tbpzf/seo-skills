### How to install (sideload)

1. Download the extension ZIP file and extract it to a folder (put it somewhere you won't accidentally delete it)
2. Open Chrome and put this in the URL bar `chrome://extensions`
3. Enable "Developer mode" using the toggle in the top right
4. Click "Load unpacked" and select the folder where you extracted the ZIP earlier
5. The extension icon will appear in your toolbar (you will need to pin it)

**Why sideload?** Google's guidelines prevent review scraping extensions in the Chrome Web Store.

## Common questions

Most issues have simple fixes. Here's what to check if something's not working.

### Extension icon is greyed out

The extension only activates on Google Search or Maps pages with a business listing. Navigate to a valid listing and try again.

### 'Something went wrong' error

Google may have changed their page structure. Wait for the page to fully load, or check [saijogeorge.com/gbp-review-scraper](https://saijogeorge.com/gbp-review-scraper/) for an updated version.

### Scraping is very slow

Listings with 500+ reviews will take longer. The extension scrolls through all reviews to ensure complete extraction. This is
normal behaviour.
